# 上一次可见的触球是谁做的？先看是什么动作

在最近 32 条可见历史里，只筛候选球队且属于主仓库十类开放比赛动作的记录，取最新一条。它不一定是窗口最后一条：对手动作、其他事件会被略过。不使用推断接球者、动作终点或目标标签构造输入。下表分母是该历史执行者仍为有效候选的样本数。统计的是同一球员是否执行目标动作，不是传球成功率，也不能确认真实的球权转移。

| 最近的己方开放比赛记录 | 主视图：同球员 / 有效分母 | 严格延迟两秒 |
|---|---:|---:|
| 传球 | 1,346 / 48,061（2.80%） | 3,449 / 47,132（7.32%） |
| 带球 / 触球 | 2,657 / 5,826（45.61%） | 2,677 / 6,753（39.64%） |
| 其他开放比赛动作 | 4,050 / 10,068（40.23%） | 2,139 / 10,229（20.91%） |

原 [角色＋归属近远](ACTOR_BASELINE.md) 的条件 logit 加一个「我是这条记录的执行者」指标，几乎不改善。再加「我是该人 × 传球」和「我是该人 × 带球／触球」，以其他开放比赛动作作参照，只增加两个系数。执行者开发 NLL 下降 **0.12471 [0.11810, 0.13138]**（主）和 **0.04555 [0.04119, 0.05005]**（延迟）。每组用相同可达样本、训练期估计、固定正则、按开发比赛配对重抽。这是相对简单加性基线的收益，不证明更强的 MLP 尚未学到同样区别，也不是动作预测提升。

保留作可解释性对照。若完整归属位模型在延迟条件下保留了执行者优势，却没有明显传到动作头，可用此诊断决定是否值得显式建模候选人和历史事件类型的交互。暂不需要换成图模型。

```bash
for view in main lag; do
  OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python candidate_mixture/last_owner_family.py \
    --canonical ../11.27 --data "real-views/$view.npz" --out "last-owner-$view.json"
done
```
