# 首轮核验

上游版本：`0323a6d37bdef72dbc57eed50d6a058e648cae61`。使用 [Wyscout 官方开放数据](https://doi.org/10.6084/m9.figshare.c.4415000.v2)重建英超 **266 场训练、57 场开发验证**，未把时序测试集送入建表或评分。

| 视图 | 训练可达 | 开发验证可达 |
|---|---:|---:|
| 主视图 | 302,919 / 303,599 | 64,975 / 65,133 |
| 延迟两秒 | 302,882 / 303,599 | 64,966 / 65,133 |

- 全量建表时核对了新增归属位所使用的事件槽位与上游 token 一致，验证标签与事件 ID、比赛 ID 和可达球员槽位对齐。可达样本计数与上游结果一致。
- `test_protocol.py` 验证了同秒和两秒边界、扰动目标和未来记录、未知执行者与 padding、候选排列等变、分布归一化和同角色调换。
- 用真实英超数据中每视图的前两场训练和前两场验证比赛做了 CPU 冒烟测试：每个比赛取 192 个可达事件，训练每场每轮抽 96 个。每视图四个实验组各训练 2 轮，均成功输出验证预测、按场配对对照和混淆矩阵。
- 这不是模型比较结果。尚未运行四组完整 120 轮、多种子或留出的时序测试；也未对两个视图的全部旧特征与归档 NPZ 做逐数组校对。
